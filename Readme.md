# 🚖 Uber Delhi Diagnostics

## 📌 Overview
This project analyzes **150,000+ Uber ride records** to understand how factors such as **distance, pricing, payment methods, and customer ratings** influence ride-sharing business performance.

Using **SQL for data querying and Python for analysis**, the project focuses on identifying **demand patterns, pricing behavior, and customer trends** through exploratory data analysis and visualization.

---

## 🎯 Objectives
- Analyze ride demand patterns over time  
- Understand the relationship between distance and fare  
- Study payment method preferences  
- Identify factors influencing customer ratings  
- Extract business insights from ride-sharing data  

---

## 🔍 Key Steps

### 1️⃣ Data Cleaning
- Removed duplicate entries  
- Handled missing values  
- Structured the dataset for analysis  

### 2️⃣ Feature Engineering
- Extracted **month, day, and hour** from ride timestamps  
- Created new metrics such as **fare per kilometer** to measure ride efficiency  

### 3️⃣ Exploratory Data Analysis
- Studied trends across **ride types, payment methods, and distance**  
- Analyzed **demand patterns and revenue trends**  
- Visualized ride distribution and performance metrics  

---

## 📊 Key Insights
- Identified **peak demand periods** based on time-based analysis  
- Analyzed how **distance influences ride pricing**  
- Evaluated **customer payment preferences**  
- Observed patterns affecting **customer ratings and ride satisfaction**
